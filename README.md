# Quest Manager

Projeto simples em Python para cadastrar, listar, excluir e atualizar o status de quests.

## Como iniciar

1. Tenha o Python 3 instalado.
2. Copie `quests.example.json` para um arquivo chamado `quests.json`.
3. No terminal, dentro desta pasta, execute `python main.py`.

O arquivo `quests.json` guarda as quests locais e não é enviado ao GitHub.
